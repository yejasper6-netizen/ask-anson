# 02 双层解释法

目的：让易懂的比喻与实际机制接上。

先用一个贴近用户任务的例子解释概念，再使用准确术语解释同一机制、成立条件及限制。列出例子里的对象分别对应什么技术对象，明确比喻在哪些地方会失真。集中解释最容易误会的一两点；最后提供三个简短理解检查题，可让用户选择是否回答，不阻塞本轮解释。

小白版与专业版必须保持相同的对象、时间范围和量的定义。讲相邻概念时先拆开各自包含与不包含的部分，检查例子和对应表是否混称、偷换边界或重复计入。不能用后面的正确定义弥补前面已经混淆的例子。

保留用户已有的知识水平。遇到近期变动的产品行为、接口或标准，先核对一手资料，并把稳定概念与当前实现分开。
