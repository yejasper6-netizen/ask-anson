# Ask Anson

**按问题选择思考方法的 AI Skill。一个入口，18 种方法与框架。**

有时，你需要把问题问清楚；有时，你需要核查一句话、看懂一个概念，或者在两条都有道理的路之间做选择。

Ask Anson 把这些场景整理成一个可以主动调用的 Skill。你只需要说清当前的困惑，它就根据问题选择合适的方法，简短说明为什么选它，再进入分析、解释或必要的追问。

不用记住一整套提示词，也不用先学会十八种方法。把问题带来，让 Ask Anson 帮你形成判断和下一步。

## 安装

下载 [Skill安装包](ask-anson.zip)，解压后把 `ask-anson` 文件夹放入你的 Codex Skill 目录。默认目录为 `~/.codex/skills/`；自定义了 `CODEX_HOME` 时使用对应的 `skills/` 目录。

安装后在新聊天中检查并调用 `$ask-anson`。本轮验证了安装文件和直接加载执行，尚未验证新会话的目录发现。

## 使用方式

调用 `$ask-anson`，接上你当前的问题。以下是使用示例：

```text
$ask-anson 我在纠结先做标准产品还是先做定制交付，帮我分析。
```

这类问题适合双向钢人论证：先把两条路各自最强的理由展开，找出真正影响选择的条件，再给出有适用范围的建议。

```text
$ask-anson 我不懂缓存失效是什么意思，结合一个生活例子和实际机制解释。
```

这类问题适合双层解释法：先听懂例子，再对照准确术语与机制，避免只记住比喻。

```text
$ask-anson 我想做一门课程，但还不知道有没有人需要。预算很少，帮我设计一个小实验。
```

这类问题适合最小实验：选出最值得验证的假设，明确投入、观察指标和继续或停止的条件。

## 十八个思考入口

| 你遇到的情况 | 可选方法 |
| --- | --- |
| 想法很多，却说不清究竟卡在哪里 | 苏格拉底式提问 |
| 能记住名词，却讲不清它怎样工作 | 双层解释法 |
| 看到一个好作品，想学会它的做法 | 反向拆解 |
| 想系统了解一个产品、技术或行业 | 横纵分析法 |
| 看到一个说法，想判断能相信到什么程度 | 事实核查 |
| 一个问题涉及不同专业，建议互相冲突 | 专家会诊 |
| 方案不断打补丁，需要重新审视根本假设 | 第一性原理 |
| 常规方法没有进展，想从其他领域找机制 | 跨领域借解 |
| 两个选项都有道理，需要比较并做选择 | 双向钢人论证 |
| 缺少现实反馈，继续空想也难以判断 | 最小实验 |
| 想从过去的经历发现自己的优势 | 挖掘隐藏天赋 |
| 想探索未来生活与职业的不同方向 | 人生设计术 |
| 方案已经基本确定，想在行动前检查会怎样失败 | 失败预演 |
| 每个环节都很忙，整体产出却没有提高 | 约束理论 |
| 数据不全，需要先估一下数量、容量、成本或工作量 | 费米估算 |
| 多个方案涉及硬门槛和多项标准，需要一致比较 | 多准则权衡 |
| 不确定当前情境适合分析、探查还是先稳定局面 | Cynefin 情境辨识 |
| 一次行动已经结束，需要从实际过程改进下一轮 | 行动后复盘 |

选法看的是当前问题的主要阻碍。例如，同样是“两个方案选不出来”，有时需要比较理由，有时需要先做实验取得反馈。Ask Anson 的入口指令要求区分这两种情况。

## 按需执行

默认一次选择一种方法，只加载相关指令。材料足够就给结果，缺少关键条件时才提问。回答篇幅跟随任务需要；访谈可以提前总结，不要求凑满问题数或写成万字报告。

你也可以直接指定方法，或调整输出方式：

```text
$ask-anson 用第一性原理，帮我重新审视这个方案。

$ask-anson 只推荐方法，暂时不要展开。

$ask-anson 只给一段可复制到其他 AI 的提示词。

$ask-anson 单轮回答，列出假设，不要进入访谈。
```

Skill 由你主动调用。事实核查和研究需要可追溯资料；专家会诊在当前模型中组织多个互补视角；估算会写出假设和范围；风险预演会区分候选风险与已知事实。判断会保留依据、适用条件和仍待确认的部分。

## 项目状态

目前已完成十八个入口文件、本地安装和按需选择规则。Astra high、Sol high、Sol low各实际回答了十个受控模拟问题；初始三十份的选法与理由均获独立模型评审认可，回答整体二十九份通过、一份轻微问题。后续对话、指令修订和控制例另行记录。这些样例尚不能证明全部场景的路由稳定性或普遍的回答质量提升。
